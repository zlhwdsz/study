Go 与 Python 的切片操作对比：

| 语言   | 切片语法                      | 可切片类型                                               | 是否复制底层数据   |
| ------ | ----------------------------- | -------------------------------------------------------- | ------------------ |
| Go     | a[low:high]                   | string -> string，按 byte 而不是 rune 索引               | 否，仅新建描述符   |
|        | a[low:high:max], max 可选     | array、*array、slice  -> slice                           |                    |
| Python | a[start:stop:step], step 可选 | list -> list, tuple -> tuple, str->str, range->range  等 | 是，但仅浅拷贝一层 |
|        |                               | memoryview、numpy/pandas array -> view                   | 否                 |
