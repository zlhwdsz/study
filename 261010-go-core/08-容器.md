# List: 带哨兵、双类型的双向链表

链表元素 Element 里，list 字段指向自己所在链表的指针，Value 字段是 any 类型，因此用的时候需要类型断言: `l.Front().Value.(int)`， 且不保证容器内的元素是同一类型。标准库没有泛型链表。

链表 List 的 root 字段是哨兵 Element。root.next 指向链表第一个元素(相应的，其 prev 指向 root)，而 root.prev 指向链表最后一个元素（相应的，其 next 指向 root），即实现上是循环链表，但逻辑上有明确的头和尾。

初始化/清空后的链表中，`root` 的前后都指向自己，而 root.next == nil 表示链表未初始化。这样让插入和删除逻辑都更简单、避免大量边界判断。

List 类型的一些方法：
- Move{Before|After|ToFront|ToBack}：将已存在于链表内的元素挪到{另一个元素前面|另一个元素后面|链表最前端|链表最后端}
- Front/Back：获取链表中最前端(头)/最后端(尾)的元素。
- InsertBefore/InertAfter：将一个新元素插入到某个元素的前面/后面。
- PushFront/PushBack：将一个新元素插入到链表最前端/最后端。

源码：GOROOT/src/container/list/list.go:
```go
// Element is an element of a linked list.
type Element struct {
	// Next and previous pointers in the doubly-linked list of elements.
	// To simplify the implementation, internally a list l is implemented
	// as a ring, such that &l.root is both the next element of the last
	// list element (l.Back()) and the previous element of the first list
	// element (l.Front()).
	next, prev *Element

	// The list to which this element belongs.
	list *List

	// The value stored with this element.
	Value any
}

// List represents a doubly linked list.
// The zero value for List is an empty list ready to use.
type List struct {
	root Element // sentinel list element, only &root, root.prev, and root.next are used
	len  int     // current list length excluding (this) sentinel element
}

// Init initializes or clears list l.
func (l *List) Init() *List {
	l.root.next = &l.root
	l.root.prev = &l.root
	l.len = 0
	return l
}

func (l *List) MoveBefore(e, mark *Element)
func (l *List) MoveAfter(e, mark *Element)

func (l *List) MoveToFront(e *Element)
func (l *List) MoveToBack(e *Element)

func (l *List) Front() *Element
func (l *List) Back() *Element

func (l *List) InsertBefore(v any, mark *Element) *Element
func (l *List) InsertAfter(v any, mark *Element) *Element

func (l *List) PushFront(v any) *Element
func (l *List) PushBack(v any) *Element
```
## 零值可用

零值可用一般是指容器对写入操作零值可用，原因都是写入时不需要初始化或会照顾初始化。

为何 List 可以开箱即用/零值可用？因为其内部操作采用了**延迟初始化**：
- Front/Back 在 l.len == 0 时直接返回 nil (包括了未初始化的情形，所以无需单独判断是否初始化)。
- Push：唯一需要按需初始化的系列操作。
- Insert/Move 函数：用于定位的元素存在于链表中(list 指针相同)，就隐含链表已经初始化的含义，不可能是零值。而若不在于链表中，则链表是否初始化未知，但函数也不关心了，因为这种情况下是直接返回了。

补充：
- ring 也是零值可用的。
- slice 也是零值可用的：`append` 被设计成会返回新 slice；append 时当发现当前 slice 没有可用容量时，会创建新的底层数组，再返回新的 slice。
- map 不是零值可用的：`m[k] = v` 是原地写入语义，写入需要真实的 hmap 结构：桶数组、哈希种子、计数、扩容状态等。`nil map` 没有这些结构，运行时不会像`append(nilSlice, x)` 那样自动分配。因此 map 类型一般用 make 初始化。而 new 也只是返回零值的指针，不会做初始化。

# Ring: 单类型、不常用的双向循环链表

源码：GOROOT/src/container/ring/ring.go:
```go
// A Ring is an element of a circular list, or ring.
// Rings do not have a beginning or end; a pointer to any ring element
// serves as reference to the entire ring. Empty rings are represented
// as nil Ring pointers. The zero value for a Ring is a one-element
// ring with a nil Value.
type Ring struct {
	next, prev *Ring
	Value      any // for use by client; untouched by this library
}
```

它支持这些操作：

| 操作                    | 作用                                                  |
| ----------------------- | ----------------------------------------------------- |
| `ring.New(n)`           | 创建 n 个元素的环；`n <= 0` 返回 `nil`                |
| `r.Next()` / `r.Prev()` | 取下一个 / 上一个元素                                 |
| `r.Move(n)`             | 向前或向后移动 n 步                                   |
| `r.Link(s)`             | 把另一个环接到 `r` 后面；如果是同一个环，也可用于切分 |
| `r.Unlink(n)`           | 从 `r.Next()` 开始移除 n 个元素，返回被移除的子环     |
| `r.Len()`               | 计算环长度，注意是 O(n)                               |
| `r.Do(f)`               | 从当前元素开始，按正向遍历每个元素                    |
| `r.Value`               | 存用户数据，类型是 `any`，需要类型断言                |

典型用途是：**循环轮转**。比如 round-robin 调度、循环播放列表、轮流处理多个 worker、游戏回合、周期性遍历一组状态。

```go
r := ring.New(3)

r.Value = "a"
r.Next().Value = "b"
r.Next().Next().Value = "c"

for i := 0; i < 5; i++ {
	fmt.Println(r.Value)
	r = r.Next()
}
```

输出逻辑是：

```text
a
b
c
a
b
```

如果只是普通队列/栈/顺序集合，通常用 `slice` 或 deque 更直接；`ring` 更适合“永远绕圈”的结构。

循环链表也有用于插入(Link)、删除(Unlink)、移动(Unlink+Link)元素的方法，不过用起来都显得更抽象一些。

# Heap: 二叉堆（仅接口&函数）

Go 的 `container/heap` 不是一个具体容器，而是一组**维护堆性质的算法函数**。你需要自己定义一个 slice 类型，并实现 `heap.Interface`。

最小可用版：

```go
package main

import (
	"container/heap"
	"fmt"
)

type IntHeap []int

func (h IntHeap) Len() int           { return len(h) }
func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] } // 小顶堆
func (h IntHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }

func (h *IntHeap) Push(x any) {
	*h = append(*h, x.(int))
}

func (h *IntHeap) Pop() any {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[:n-1]
	return x
}

func main() {
	h := &IntHeap{3, 1, 5}
	heap.Init(h)

	heap.Push(h, 2) // 通过调用标准库函数，来间接调用自己定义的 Push 方法。

	for h.Len() > 0 {
		fmt.Println(heap.Pop(h))
	}
}
```

输出：

```text
1
2
3
5
```
