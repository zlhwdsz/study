# 本质
map、channle、func 的本质都是指向结构体的指针。所以它们的零值 nil，是 0x0。

string、slice、interface 的本质是结构体，所以它们的零值 ""/nil 不是简单的 0x0。

# 闭包

闭包：存在对外来标识符/自由变量的引用的函数。

外来标识符/自由变量：既不是当前函数的任何入参或出参，也不是函数内部声明的局部变量，而是直接从外边拿过来的。

函数会因为引用了自由变量，而呈现出了一种“不确定”的状态，也叫“开放”状态：它的内部逻辑并不是完整的，有一部分逻辑需要这个自由变量参与完成，而后者除了类型外，其到底代表了什么在闭包函数被定义的时候却是未知的。

自由变量 op 究竟代表了什么，这一点并不是在定义这个匿名闭包函数的时候确定的，而是在 genCalculator 函数被调用的时候确定的。有给定了该函数的参数op，我们才能知道它返回给我们的闭包函数可以用于什么运算。

```go
func genCalculator(op operate) calculateFunc {
  return func(x int, y int) (int, error) {
    if op == nil { // Go 语言编译器读到这里时会试图去寻找op所代表的东西，它会发现op代表的是genCalculator函数的参数，然后，它会把这两者联系起来。这时可以说，自由变量op被“捕获”了。
      return 0, errors.New("invalid operation")
    }
    return op(x, y), nil
  }
}

// 当程序运行到这里的时候，op就是那个参数值了。如此一来，这个闭包函数的状态就由“不确定”变为了“确定”，或者说转到了“闭合”状态，至此也就真正地形成了一个闭包。
```
