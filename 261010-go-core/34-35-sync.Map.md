sync.Map Go 1.9 加入标准库，并发安全，存、取、删时间复杂度O(1)。用锁，但尽可能地避免用锁。

键、值的类型是都 any。但若键（某些方法还包括值:CompareAndSwap/CompareAndDelete）的实际类型不是 comparable（可判等） 的，也会像 map[any]any 一样引起运行时 panic。

# 怎样保证并发安全字典中的键和值的类型正确性？

## 封装，指定具体类型

优点：让 Go 语言编译器帮忙做类型检查。
缺点：无法灵活地改变字典的键和值的类型。换一种类型，又得重新写一遍几乎雷同的代码。

```go
type IntStrMap struct {
 m sync.Map
}

func (iMap *IntStrMap) Delete(key int) {
 iMap.m.Delete(key)
}

func (iMap *IntStrMap) Load(key int) (value string, ok bool) {
 v, ok := iMap.m.Load(key)
 if v != nil {
  value = v.(string)
 }
 return
}

func (iMap *IntStrMap) LoadOrStore(key int, value string) (actual string, loaded bool) {
 a, loaded := iMap.m.LoadOrStore(key, value)
 actual = a.(string)
 return
}

func (iMap *IntStrMap) Range(f func(key int, value string) bool) {
 f1 := func(key, value interface{}) bool {
  return f(key.(int), value.(string))
 }
 iMap.m.Range(f1)
}

func (iMap *IntStrMap) Store(key int, value string) {
 iMap.m.Store(key, value)
}
```

## 封装，通过反射进行类型检查

优点：灵活。
缺点：运行时才检查，同时降低性能。

```go
type ConcurrentMap struct {
 m         sync.Map
 keyType   reflect.Type
 valueType reflect.Type
}

func (cMap *ConcurrentMap) Load(key interface{}) (value interface{}, ok bool) {
 if reflect.TypeOf(key) != cMap.keyType {
  return
 }
 return cMap.m.Load(key)
}

func (cMap *ConcurrentMap) Store(key, value interface{}) {
 if reflect.TypeOf(key) != cMap.keyType {
  panic(fmt.Errorf("wrong key type: %v", reflect.TypeOf(key)))
 }
 if reflect.TypeOf(value) != cMap.valueType {
  panic(fmt.Errorf("wrong value type: %v", reflect.TypeOf(value)))
 }
 cMap.m.Store(key, value)
}
```
## 封装，泛型

```go
func main() {
	var m MySyncMap[int, string]
	m.Store(1, "abc")
	fmt.Println(m.Load(1))
}

type MySyncMap[TK comparable, TV any] struct {
	m sync.Map
}

func (iMap *MySyncMap[TK, TV]) Delete(key TK) {
	iMap.m.Delete(key)
}

func (iMap *MySyncMap[TK, TV]) Load(key TK) (value TV, ok bool) {
	v, ok := iMap.m.Load(key)
	if v != nil {
		value = v.(TV)
	}
	return
}

func (iMap *MySyncMap[TK, TV]) LoadOrStore(key TK, value TV) (actual TV, loaded bool) {
	a, loaded := iMap.m.LoadOrStore(key, value)
	actual = a.(TV)
	return
}

func (iMap *MySyncMap[TK, TV]) Range(f func(key TK, value TV) bool) {
	f1 := func(key, value interface{}) bool {
		return f(key.(TK), value.(TV))
	}
	iMap.m.Range(f1)
}

func (iMap *MySyncMap[TK, TV]) Store(key TK, value TV) {
	iMap.m.Store(key, value)
}
```

# 并发安全字典如何做到尽量避免使用锁？

sync.Map 类型在内部使用了大量的原子操作来存取键和值。

Go 1.26 以前：使用`read/dirty` 双原生 map，将不会发生结构变化的数据放入`read` ，将需要修改的数据放入`dirty`。

Go 1.26+：使用 HashTrieMap (Go 1.24 通过 GOEXPERIMENT=synchashtriemap 引入)
