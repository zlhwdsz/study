```go
// 读出来，写到 []byte 中去，读多少由 []byte 长度决定。
type Reader interface {
    Read(p []byte) (n int, err error)
}

// 读出来，写到 Writer 中去，读全。
type WriterTo interface {
    WriteTo(w Writer) (n int64, err error)
}

// 从 []byte 中读出来，写到自己。读多少由 []byte 长度决定。
type Writer interface {
    Write(p []byte) (n int, err error)
}

// 从 Reader 中读出来，写到自己
type ReaderFrom interface {
    ReadFrom(r Reader) (n int64, err error)
}
```

核心区别：
- `Reader` /`Writer` ：每次处理一块数据，外部调用者负责循环。
- `WriterTo` ：源对象负责把剩余数据全部写入目标。
- `ReaderFrom` ：目标对象负责从源读取，直到 EOF。


```go
type ReaderAt interface {
	ReadAt(p []byte, off int64) (n int, err error)
}
```

ReadAt 与 Read 的区别：
- ReadAt 不被 seek offset 影响，也不影响它。
- ReadAt 读不够时可能会阻塞。
- ReadAt 返回不够长的结果时，一定会返回非 nil 的错误。
