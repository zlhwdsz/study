# cp

若不带 -r/-R/--recursive，会跳过目录源。

```text
用法：cp [选项]... [-T] 源 目标
　或：cp [选项]... 源... 目录
　或：cp [选项]... -t 目录 源...
将 <源> 复制至 <目标>，或将多个 <源> 复制至 <目录>。

  -t, --target-directory=目录  将所有 <源> 参数复制到 <目录>
  -T, --no-target-directory    将 <目标> 视为普通文件

  -p                           等于--preserve=mode,ownership,timestamps
      --preserve[=属性列表]    保留指定的文件属性
      --no-preserve=属性列表   不保留指定的属性
  -a, --archive                等于 -dR --preserve=all
  -d                           等于 --no-dereference --preserve=links
  -l, --link                   硬链接文件以代替复制
  -L, --dereference            总是跟随 <源> 里的符号链接
  -P, --no-dereference         从不跟随 <源> 里的符号链接
```

可见：
- 多个源时，要求目标必须是存在的目录，命令将所有源按原名复制进目录内。
- 单个源时：
  - 当目标是存在的目录时，命令将源按原名复制进目录内。
  - 当目标是存在的文件时，要求源也是文件，目标不换名但换内容。
  - 当目标不存在，但其上级目录存在时，会发生复制+重命名。

# mv

```text
用法：mv [选项]... [-T] 源 目标
　或：mv [选项]... 源... 目录
　或：mv [选项]... -t 目录 源...
将 <源> 重命名为 <目标>，或将 <源> 移动至 <目录>。
```

可见：
- 多个源时，要求目标必须是存在的目录，命令将所有源按原名移动进目录内。
- 单个源时：
  - 当目标是存在的目录时，命令将源按原名移动进目录内。
  - 当目标是存在的文件时，要求源也是文件，目标不换名但换内容。
  - 当目标不存在，但其上级目录存在时，会发生移动+重命名。

# 通配符

- * 0~无穷多个任意字符
- ? 一个任意字符
- \[0-1ax-z\]: 0、1、a、x、y、z
- \[!0-1ax-z\] 或 \[^0-1ax-z\]: 不匹配相关字符

Shell 通配符不能像正则那样表示确定的数量，且 * 和 ? 的语义也不一样。

另：花括号展开（Brace Expansion）:由 Shell 在执行命令前展开，不属于通配符或正则表达式。

```bash
{1..10}     # 1 2 3 ... 10
{a..e}      # a b c d e
{a..e..2}  # a c e，步长为 2
printf 'a%.0s' {1..5} # 打印 aaaaa
```
