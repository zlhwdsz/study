VIM - Vi IMproved，增加无穷步骤的回退和重做。

四种模式：
- 正常模式 Normal：初始模式，以及其他模式下按 ESC 进入。此模式下的命令不需按回车即执行：包括复制、剪切、粘贴、撤销等。
- 插入模式 Insert：正常模式下按 i/I/a/A/o/O/\ds/S/cw/c$/cc 进入，然后键盘输入为内容。
- 命令行/末行/底行模式 Command-line：正常模式下按 :、/ 或 ? 进入。此模式下的命令需要按回车才会执行。
- 可视模式 Visual：正常模式下按 v、V 或 ctrl+v 进入。

# 正常模式

方向命令（字符终端可能不支持方向键）：
- h ←
- j ↓
- k ↑
- l →

跳转命令：
- \dG(go): 跳转到指定行(命令模式 :set nu 开启行号显示)，默认末行。
- gg：跳转到首行
- ^: 移动到行首
- $: 移动到行尾

剪切板操作命令：
- y$(yank): 复制至行尾；\dyy: 复制若干行，默认1行。
- d$(delete)：剪切至行尾(不含换行符)；\ddd: 剪切若干行，默认1行。
- \dx：剪切若干字符，默认1。
- p(paste): 若剪贴板的内容是整行，则在下粘贴，否则在后粘贴。P: 在上/前粘贴。

编辑命令：
- \dr(replace): 将当前及后续若干(默认1)个字符替换为相同的某个字符(不进入插入模式)

撤销/重做命令：
- u(undo): 撤销，可多次。
- ctrl+r(redo): 重做，可多次。

# 插件模式

在正常模式下按以下键：
- i：光标当前位置，I：当前行第一个非空白字符前
- a：光标当前位置之后(append)，A：当前行尾
- o：在下开新行(open line)，O：在上开新行
- \ds(substitute)：删除若干（默认1）个字符然后进入插入模式，S：修改整行，即清空整行(但不含换行符)然后进入插入模式，等价于 cc。
- c(change)：cw 修改至单词末，c$ 修改至行尾，cc 修改整行，均进入插入模式

# 命令行模式

保存：
- :w[q] [dst]

临时执行 shell 命令：
- :! 

查找和替换：
- / 向下查找，? 向上查找, n 下一个， N 上一个。
- :s/old/new 在本行替换一次
- :s/old/new/g 在本行替换全部
- :%s/old/new 在每行替换
- :3,5s/old/new 在第3~5行替换

临时设置：
- :set nu(mber) 显示行号，:set nonu 不显示行号
- :set hlsearch 高亮搜索，:set nohlsearch 取消高亮搜索

若要永久生效，则在以下配置文件中添加 set nu 等：
- 系统配置：/etc/vimrc 或 for mac: /usr/share/vim/vimrc
- 用户配置：~/.vimrc, 或 for mac: ~/.vim/vimrc, ~/.config/vim/vimrc

# 可视模式

在正常模式下按：
- v: 字符可视模式
- V: 行可视模式
- ctrl+v: 块可视模式

选中后，按 d 删除，按 c/s 删除且进入插入模式。

块可视模式下，按 I 进入插入模式，再连按两次 ESC，所输入内容会插入所选中区块的每一行开头。
