- useradd 添加用户（只有 root 能操作）：创建用户的家目录，在 /etc/passwd()、/etc/shadow() 中添加记录。
  - -g/--gid 设置用户组
  - /etc/passwd 与 /etc/shadow
    - `/etc/passwd` ：保存用户的 基本账户信息 ，如用户名、UID、GID、家目录和登录 Shell。通常所有用户可读。
      - alice:x:1001:1001::/home/alice:/bin/bash, 其中`x` 表示密码哈希存放在`/etc/shadow` 。
    - `etc/shadow` ：保存敏感的 认证信息 ，如密码哈希、密码有效期、过期时间和锁定状态。只有特权进程可以读取。
    - 之所以分开，是因为系统需要公开 UID 与用户名的对应关系，但不能公开密码哈希。`passwd` 这个文件名是历史遗留，现代 Linux 通常不再把密码哈希直接存在其中。
- passwd 修改用户的密码（默认自己）
- usedel 删除用户, -r/--remove 同时删除主目录和信件池。
- id 查看单个用户(默认自己)
- cat /etc/passwd 查看所有用户
- usermod 修改用户属性，比如 -d/--home 修改家目录， -g/--gid 修改用户组。
- chage 修改用户及其密码过期时间

- groupadd 添加用户组
- groupdel 删除用户组
