- useradd 添加用户（只有 root 能操作）：创建用户的家目录，在 /etc/passwd()、/etc/shadow() 中添加记录。
  - -g/--gid/ 设置主用户组，-G/--groups 设置附加用户组(以逗号隔开)，两个选项的参数都同时接受数字的 GID 和字符串的组名作为参数。
    - 一个用户只有一个主组，主组 GID 记录在`/etc/passwd` ，通常是新建文件的默认所属组。
    - 附加组可以有多个；用于获得额外资源或权限。
  - /etc/passwd 与 /etc/shadow
    - `/etc/passwd` ：保存用户的基本账户信息，通常所有用户可读。格式7字段：`用户名:密码占位符:UID:主组GID:用户描述:家目录:登录Shell`，比如 `alice:x:1001:1001:Alice:/home/alice:/bin/bash`
      - 密码`x` 表示密码哈希存放在`/etc/shadow`
      - 登录 Shell 为 `/sbin/nologin` 表示禁止交互登录。
    - `etc/shadow` ：保存敏感的认证信息，只有特权进程可以读取。格式9字段：`用户名:密码哈希:最后修改日:最短期限:最长期限:警告期:失效宽限期:账户到期日:保留`，比如 `alice:$y$j9T$...:20750:0:99999:7:::`
      - 密码字段以`!` 或`*` 开头：通常表示密码登录被锁定或不可用。
    - 之所以分开，是因为系统需要公开 UID 与用户名的对应关系，但不能公开密码哈希。`passwd` 这个文件名是历史遗留，现代 Linux 通常不再把密码哈希直接存在其中。
  - 另有 `adduser` 命令，在不同发行版中的行为不统一，比如在 centos 中就是 useradd 的符号链接，在 ubuntu 中则是 `useradd` 的高级交互式封装，会询问信息、设置密码并创建家目录。
- passwd 修改用户的密码（默认自己）
- usedel 删除用户, -r/--remove 同时删除主目录和信件池。
- id 查看单个用户(默认自己)
- cat /etc/passwd 查看所有用户
- usermod 修改用户属性，比如 -d/--home 修改家目录， -g/--gid 修改主用户组，-G/--groups 设置附加用户组(覆盖旧设置), -aG 追加附加用户组
- chage 修改用户及其密码过期时间

- groupadd 添加用户组
- groupdel 删除用户组

- `/etc/group` 定义所有本地用户组，格式4字段：`组名:组密码:GID:成员列表`，比如`wheel:x:10:bob,alice`
  - 组密码 x 表示密码信息放在 /etc/gshadow 中
  - 成员列表表示以逗号分隔，主要列出附加成员。用户的主组记录在`/etc/passwd` 的 GID 字段中，因此主组成员不一定出现在这里。
- `/etc/gshadow` 保存用户组的敏感信息，通常只有特权进程可以读取。格式4字段：`组名:组密码哈希:组管理员列表:组成员列表`，比如`developers:!:alice:bob,carol`
  - 组密码哈希为 `!` 或 `*` 时，表示不能使用组密码加入该组。组密码功能现在很少使用。
  - 组管理员列表和组成员列表均以逗号分隔；组管理员可以管理该组的密码和成员。
  - `/etc/group` 与 `/etc/gshadow` 中的组名和成员信息应保持一致。
