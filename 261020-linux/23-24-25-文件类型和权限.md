# 文件类型
- -:普通文件
- d 目录文件，directory
- b 块设备文件，block，比如硬盘 /dev/sd*
- c 字符设备文件，charecter，比如终端 /dev/null, /dev/tty
- l 符号链接
- p 命名管道，`mkfifo` 命令可生成。用于进程间通信，通常是简单的单向字节流，适合一个进程写、另一个进程读。
- s Unix 域套接字，如：/run/systemd/private、/run/dbus/system_bus_socket、/var/run/docker.sock。也用于同一主机上的进程间通信：支持双向通信、多个客户端连接和客户端身份识别。与之相对的是网络套接字：还能让不同主机上的进程通过 IP 和端口通信。

# 文件权限

普通文件的权限：读 r=4, 写 w=2，执行 x=1，用户(u)、组内用户(g)、其他用户(o)。
- 新文件的所属组默认是创建进程的有效组；如果父目录设置了 SGID 权限，新文件会继承父目录的所属组。
- 如果用户同时满足 u 和 g，权限以 u 为准。

普通文件默认权限 666 & ~`umask`(默认为0022)=644="-rw-r--r--"。umask: user file-creation mode mask。

目录文件的权限：
- r=4，读取目录项，可以列出目录中的文件名，如 `ls dir`。
- w=2，修改目录项，可以在目录中创建、删除和重命名文件；实际操作通常还需要 x 权限。
- x=1，搜索和进入目录，可以通过已知文件名访问目录中的文件，也可以执行 `cd dir`。

目录文件默认权限 777 & ~`umask`，即 755, "drwxr-xr-x"。 

常见组合：
- r+x：可以列出文件名，并访问文件、查看其属性。
- 只有 r：可以列出文件名，但无法继续访问文件或查看其完整属性。
- 只有 w：既不能列出目录项，也不能通过文件名访问目录项，因此通常无法创建、删除或重命名文件；w 权限需要与 x 权限配合才有实际作用。
- 只有 x：不能列出文件名，但知道文件名时可以访问该文件。
- w+x：可以创建、删除和重命名目录中的文件。删除文件主要取决于父目录的 w+x 权限，而不是文件自身的写权限(比如 vi 的工作方式)；还可能受到粘滞位、ACL、只读文件系统等限制。

修改权限/隶属关系命令：
- chmod, u g o a, +-=
- chown 更改 属主:属组
- chgrp 单独更改属组

# 特殊权限

特殊权限位于四位八进制权限的最高位：SUID=4、SGID=2、SBIT=1，可以组合使用。例如 `chmod 6755 file` 同时设置 SUID 和 SGID。

## SUID（Set User ID）, 4, 占 ux，s/S

- 主要用于可执行文件。用户执行该文件时，进程的有效用户 ID（EUID）临时变为文件属主，而不是执行者本人。
- 典型示例是 `/usr/bin/passwd`：普通用户通过它以文件属主 root 的权限修改 `/etc/shadow`，但只能执行程序允许的操作。
- 在 `ls -l` 结果中占用属主的 x 位：`s` 表示同时具有 SUID 和 x，`S` 表示设置了 SUID 但没有 x。
- 设置方式：`chmod u+s file` 或 `chmod 4755 file`；取消方式：`chmod u-s file`。
- SUID 通常只对二进制可执行文件有意义；Linux 出于安全考虑会忽略脚本文件的 SUID。

## SGID（Set Group ID）, 2, 占 gx，s/S

- 用于可执行文件时，进程的有效组 ID（EGID）临时变为文件所属组。
- 用于目录时，该目录中新建的文件和子目录会继承父目录的所属组，而不是创建进程的有效组；新建的子目录通常还会继承 SGID 位，适合团队共享目录。
- 在 `ls -l` 结果中占用属组的 x 位：`s` 表示同时具有 SGID 和 x，`S` 表示设置了 SGID 但没有 x。
- 设置方式：`chmod g+s file_or_dir` 或 `chmod 2755 file_or_dir`；取消方式：`chmod g-s file_or_dir`。
- 共享目录示例：`chmod 2775 shared`。

## SBIT（Sticky Bit，粘滞位）, 1, 占 ox, t/T, /tmp

- 主要用于多人可写的目录。设置后，即使用户对目录具有 w+x 权限，也只能删除或重命名自己拥有的文件；目录属主和 root 不受此限制。
- 它不限制对文件内容的修改，能否修改内容仍由文件自身的权限决定。
- 典型示例是 `/tmp`，权限通常为 `1777`，显示为 `drwxrwxrwt`。
- 在 `ls -l` 结果中占用其他用户的 x 位：`t` 表示同时具有 SBIT 和 x，`T` 表示设置了 SBIT 但没有 x。
- 设置方式：`chmod +t dir` 或 `chmod 1777 dir`；取消方式：`chmod -t dir`。
- 在现代 Linux 中，普通文件上的 SBIT 通常没有实际作用。
