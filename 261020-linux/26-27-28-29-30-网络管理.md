# 早期：net-tools

## 查看

`ifconfig` (interface config): 可接网卡名称单独查看一个网卡
- inet (internet)：IPv4 地址。
- ether: mac 地址。
- RX（Receive） ：网卡接收的数据，即网络 → 本机。
- TX（Transmit） ：网卡发送的数据，即本机 → 网络。 

网卡名改为 eth0 风格：
- /etc/default/grub 中 GRUB_CMDLINE_LINUX 添加 net.ifnames=0 biosdevname=0
- 更新配置：sudo grub2-mkconfig -o /boot/grub2/grub.cfg
- 重启：reboot

`mii-tool`: 查看网卡物理连接状态。

`route`：查看网关、路由，-n/--numeric 不解析主机名以节约时间。

`netstat`(见下文)

## 修改

设置网卡 ip: ifconfig <接口> <IP地址> [netmask 子网掩码]

启用/禁用网卡：ifup / ifdown，或者 ifconfig <if> up/down

管理路由：route add/del，gw 是 gateway 的缩写。

# 网络故障排查

## 主机问题

ping：通否

traceroute: 追踪每一跳的质量

mtr（my traceroute）：显示更详细的信息

nslookup: 查域名对应的 ip

## 服务问题

telnet：检查端口连接状态（可能需要 yum install）

tcpdump: 更细致地分析数据包

netstat/ss: 查看监听状态

# 配置固化

用于网络管理的 systemd 服务：NetworkManager

网卡配置文件：/etc/NetworkManager/system-connections/*.nmconnection

临时改主机名：hostname

永久改主机名：hostnamectl set-hostname, 最好在 /etc/hosts 中添加新主机名解析为 127.0.0.1
