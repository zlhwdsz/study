# 包管理器

- Debian 系（含 Ubuntu）软件安装包格式为 .deb，包管理器为底层的 dpkg 和处理软件源和依赖的 apt (Advanced Pakcage Tool)。
- RedHat 系（含 CentOS）软件安装包格式为 .rpm，包管理器为底层的 rpm (RedHat Package Manager / RPM Package Manager)和处理软件源和依赖的 yum(Yellowdog Updated, Modified)/ dnf (dandified yum, from CentOS 8)

## rpm

rpm 包格式：vim-common-7.4.10-5.el7.x86_64
- vim-common: 软件名
- 7.4.10-5.el7：包版本
  - 7.4.10：软件版本
  - 5.el7：打包发行号
    - 5：打包修订号，通常递增
    - el7：系统版本，el 是 Enterprise Linux 的意思
- x86_64: 平台架构类型

查看所有安装的包：rpm -qa，查看安装的单个包： rpm -q 包名（可依次省略至只含软件名）

安装: rpm -i 文件.rpm, 卸载：rpm -e (erase) 包名。

## yum/dnf

install, upgrade, remove, list, info, search

编译源码报错缺 XXX Library 时，可以考虑 `dnf install XXX-devel`。
