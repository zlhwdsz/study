# 磁盘分区：fdisk -l， parted -l

disk: fixed disk

ls -l /dev/sd*: 对于磁盘设备文件来说，在文件大小的字段处，显示的是 "主设备号, 从设备号"。
- 主设备号：用什么驱动程序。
- 从设备号：确定访问地址。

```bash
8, 0 /dev/sda
8, 1 /dev/sda1 # 分区，最多分15个区
8, 2 /dev/sda2
8, 3 /dev/sda3
8, 16 /dev/sdb
8, 32 /dev/sdc
```

# 磁盘挂载和用量：df, disk free

如果是 ext4 文件系统，会从超级块中快速拿到信息，而不是每个文件逐一统计。

# 目录占用：du, disk usage

由于空洞的存在，同一个文件，du 看到的大小可能会小于 ls -l 看到的大小！

# 按块读写：dd, data duplicator

和普通`cp` 不同，`dd` 更偏底层，按块读写，可以直接操作设备文件：

```bash
# if: input file, of: output file, bs: block size
dd if=/dev/zero of=afile bs=4M count=10 # afile: ls -l 和 du 都是 40M。
dd if=/dev/zero of=bfile bs=4M count=10 seek=20 # ls -l 显示 120M（只查看 inode）, du 显示 40M (会查看 data block)。
```

# 文件系统

CentOS: ext4 -> xfs.

ext4 结构：
- 超级块
- 超级块副本
- i 节点(inode): 文件大小、编号、权限等，以及目录下的文件名（所以一个文件 inode 不会记录自身的名称。当目录内文件太多时，还会记录到目录的 datablock 里）。
- 数据块(data block)：多个数据块会形成链接结构。
